NEON SWARM is an arena survival shooter set against an endless neon onslaught.
Fight off enemies, collect XP, and choose upgrades to keep your run alive.

## How to play

Enter the arena and survive for as long as you can.
Defeated enemies drop XP; collect it to level up and choose an enhancement.

| Control | Action |
| --- | --- |
| WASD or arrow keys | Move |
| Mouse | Aim |
| Hold left click or Space | Fire |
| Click a card or press 1, 2, or 3 | Choose an upgrade |
| P or Esc | Pause or resume |
| M | Mute or unmute |
| Enter | Start from the title screen |
| R | Restart after a run |

Keep moving, aim carefully, and build your upgrades around your play style.

## Run locally

From the repository root, start the local server:

```sh
node serve.ts
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

You can also open `game/index.html` directly in a browser.
